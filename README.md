## Description

WPS (abbreviation of “WordPress-plugin-starter”) is a WordPress plugin boilerplate with the developmental purpose of any other WordPress plugin in less time.
The whole plugin is implemented in the FACADE design pattern for stability and compatibility with any newly created feature, So the plugin performs highly
customizable and flexible.
